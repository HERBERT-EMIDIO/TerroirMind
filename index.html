Foto do rótulo: chave do Gemini (grátis)

  1. Entre em aistudio.google.com/apikey com uma conta Google.
  2. Clique em Create API key e copie a chave.
  3. Cole abaixo e salve.

A chave fica só neste navegador. A foto vai para o Google, que apenas transcreve o rótulo; o perfil sensorial e as notas saem do catálogo do TerroirMind, nunca da IA. No plano grátis, o Google pode usar o envio para melhorar os produtos dele.
